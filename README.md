# Природа — ближе, чем кажется

Адаптивный информационный сайт о природе на русском языке. Проект знакомит с лесами, горами и круговоротом воды и рассказывает, как бережнее относиться к окружающему миру.

Сайт написан на **HTML и CSS**, без JavaScript, фреймворков и сборки.

## Что есть на сайте

- Главный экран с фотографией леса.
- Вступительный раздел о природе и взаимосвязях в ней.
- Карточки лесов, гор и воды со ссылками на подробные описания.
- Советы по бережному отношению к природе.
- Навигация по разделам с плавной прокруткой.
- Адаптивная вёрстка для компьютеров, планшетов и телефонов.

Для доступности добавлены описания изображений, ссылка для перехода к основному содержимому и видимое выделение ссылок при навигации с клавиатуры. При включённой настройке уменьшения движения плавная прокрутка и эффекты переходов отключаются.

## Запуск

1. Скачайте проект или клонируйте репозиторий.
2. Откройте файл `index.html` в браузере.

Устанавливать зависимости не нужно. Для разработки также можно использовать расширение **Live Server** в VS Code.

## Структура проекта

```text
├── index.html   # Содержимое страницы и навигация
├── style.css    # Оформление, эффекты и адаптивная вёрстка
└── README.md    # Описание проекта
```

## Технологии и оформление

- **HTML5** — семантическая структура страницы.
- **CSS3** — оформление, сетки Grid, Flexbox и медиазапросы.
- **Manrope** — основной шрифт.
- **Playfair Display** — шрифт для акцентных надписей.
- Зелёная цветовая палитра и фотографии природных ландшафтов.

## Внешние ресурсы

Фотографии загружаются с [Unsplash](https://unsplash.com/), а шрифты — через [Google Fonts](https://fonts.google.com/). Для их загрузки требуется подключение к интернету. Если шрифты недоступны, браузер использует запасные системные шрифты.

## Как изменить сайт

- Тексты, названия разделов и ссылки редактируются в `index.html`.
- Цвета задаются CSS-переменными в блоке `:root` файла `style.css`.
- Изображения можно заменить через атрибуты `src` в HTML и свойства `background` в CSS.
- Настройки отображения на небольших экранах находятся в медиазапросах в конце `style.css`.

При изменении идентификаторов разделов (`id`) обновляйте соответствующие ссылки (`href="#..."`), чтобы навигация продолжала работать.
